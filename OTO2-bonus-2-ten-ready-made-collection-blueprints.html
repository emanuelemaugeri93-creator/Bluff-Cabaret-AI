10 Ready-Made Collection Blueprints

Ten complete series plans built from the real topic banks of the Pro Edition: a world, a recurring host, three topics, a release order and a series name. Pick one, tune it in the editor, plan the releases and type it into Step 4: Collection in the Pro Edition.

How to use these blueprints

The idea in one minute

Starting a series means answering the same questions every time: which world, which host, which topics, in what order, with what name? A blueprint answers all of them for you, using real topics from the Pro Edition's topic banks. You can use a blueprint exactly as it is, change anything you like, or build your own from scratch with the same tools.

Quick start

  1. Open 1 Blueprints and pick the series that suits you. Read the host and the three topics. Not sure which? Use 5 Find my blueprint.
  2. Press Copy setup. Then open the Pro Edition, go to Step 4: Collection, stay on the Plan tab, and type the Collection name.
  3. Under One recurring host choose A character from the first game's cast and pick the Character named in the setup.
  4. For every game set the World, the Edition, the Card format and type the Topic.
  5. Open the Planner tab for the suggested launch order, Bundles for bundle ideas and Series Kit for the series logo, the shared card back and the collection cover prompts.
  6. Before you build, use 6 Topic check to avoid overlap, 7 Workload to size the job and 8 Series bible for your one-page reference.
  7. Continue to Step 5, run the checks and copy your production script.

Tips

  • A collection holds 2 to 6 games. Start with three and add more when the first ones are done.
  • The host comes from the first game's cast. Pick a character whose personality fits the topics.
  • Keep one card format across the games at first. Add other sizes later with the same topics.
  • Topics are starting points. Verify every fact with reliable sources before you print or sell.
  • Give every game its own final title and check that it does not clash with an existing product.

If something goes wrong

The copy button does nothing
Click inside the setup text, select all and copy by hand.
My topic is not in the bank
Type it as a custom topic in the editor. The Pro Edition accepts any topic.
I changed the world and lost my topics
Topics belong to a world. Changing the world starts a fresh list, so choose the world first.
The calendar months look odd
Check the start month and the rhythm. The plan only suggests: you decide the dates.

All blueprints are planning aids built from the Pro Edition's data. They are not predictions and they promise no result. Your work is saved in this browser.

How to use the planner

The idea in one minute

One theme can feed three different games: a bluffing game, a spot-the-false-statement game and a head-to-head quiz. Planning them together saves time, because the research, the world and the brand stay the same. This planner helps you decide which topic leads each game, what to call them, in what order to release them and how to offer them together.

Quick start

  1. Not sure what to build? Open 6 Lineup library, pick a world and press Load into the planner. Or open 1 Theme, choose a world and a theme, and press Suggest a lineup.
  2. Open 2 Names, add your brand line and copy the names you like.
  3. Open 3 Release order, pick a strategy, a start month and a rhythm.
  4. Skim 4 Put them together for pairings you can offer.
  5. Open 7 Pitches & workload to choose the lead game for your players and see how long the work will take.
  6. Open 5 My lineup, tick the steps as you build, and print the one-page planner with the button at the top.

Tips

  • Start with the game you have already built. A finished game is the fastest first release.
  • Give every game its own final title, and check that it does not clash with an existing product.
  • All three games use Poker size cards, 63 x 88 mm, on A4 or US Letter.
  • The true statements and correct answers come from sourced topic banks. The false statements and wrong options are written by ChatGPT: check them before you print or sell.
  • Test each deck with two or three people before you release it.

If something goes wrong

The topic I want is not in the bank
Choose "My own words" for the theme. The names, the order and the pairings work with any theme.
A name is too long
The names tab flags anything over 80 characters. Use a shorter theme or brand line.
My dates look wrong
Check the start month, the year and the rhythm.
The copy button does nothing
Select the text by hand and copy it.

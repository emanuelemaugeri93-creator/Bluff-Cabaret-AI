How to use this playbook

The idea in one minute

A bundle is a group of products that belong together: three games from one world, one topic in two sizes, a game with its add-on packs. This playbook gives you twelve proven shapes for a bundle, so you never start from a blank page. For each shape you get what goes inside, naming patterns, a release order, what to keep consistent and where to build it in the Pro Edition.

Quick start

  1. Open 1 Layouts and use the goal filters. Read the layouts that fit and pick one.
  2. Open 2 Name generator, choose the layout and your world, type or choose your topics, and copy the name you like.
  3. Open 3 Release order and set a start month and a rhythm. Copy the plan.
  4. Build the bundle in the Pro Edition with the tools named in the layout: Step 2 (Edition and Format) for card format and edition, Step 3 (Expansions) for expansion packs, and Step 4 (Collection, with the Plan, Planner, Bundles and Series Kit tabs) for series and bundles.
  5. Short on ideas? Open 6 Ready-made bundles, pick a world and use Add to my planner. Open 7 Setup & workload to see how big the job is.
  6. Open 4 My planner, add the bundle and tick the checklist as you go.

Five rules for every bundle

  1. Singles first, bundle last. Publish each game on its own, then the bundle that groups them.
  2. One look. Same host, same card back and same series name.
  3. Name it plainly. A buyer should understand what is inside from the name.
  4. Verify once, reuse everywhere. One fact log per topic. Sizes and editions share the same facts.
  5. Test before you promise. Print and test every size you sell.

If something goes wrong

The copy button does nothing
Click inside the text, select all and copy by hand.
A name is too long
The generator flags names over 80 characters, the length the Collection name field accepts. Use a shorter pattern or a shorter series name.
My dates look wrong
Check the start month, the year and the rhythm. For seasonal layouts, check the "count back" option.
My plan disappeared
It is saved in this browser. Clearing your browser data removes it, so download the planner now and then.

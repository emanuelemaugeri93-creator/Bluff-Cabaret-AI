How to use the shot list

The idea in one minute

A store listing shows a row of images, and each one has a job. The first says what the product is. The next ones show what the buyer gets, what the cards look like, how the game works and how big it is. This page gives you a set of twelve images in a sensible order. For each one it tells you what to show, which Boxed Game Studio tool makes it, and the best image format. You tick each image off as you make it.

The shot list tells you what to make. It does not make the images and it does not promise that any image will help a listing. The images of your own product are made by the Studio from your own cards. The styled scene (frame 12) is made by ChatGPT from a prompt, so check it before you use it.

Quick start

  1. In the left panel, choose what you sell and type your game name.
  2. Open Boxed Game Studio with your game loaded. In Station 4 (Photos) there are three tabs: Mockup Builder (one image at a time), Listing Images (five images in one ZIP) and Photo prompts (six prompts for ChatGPT). Open How to make it in each frame to see the exact steps.
  3. Set each frame to Made when the image exists. Type the file name you saved it under.
  4. Look at the set side by side on your phone. Set each frame to Checked when it reads clearly.
  5. Check the image text and choose your look in the style sheet before you download the images.
  6. Review the styled scene before you use it. Rename the files so the set stays in order.
  7. Print the list with the button at the top, or download it as a file.

Tips

  • Keep the order. The first image is the one people see before they open the listing.
  • Show only what the buyer will really receive. A printable download is not a box.
  • Use the same look across all images: same background, same game name.
  • Read each image at phone size. If you cannot read it there, make the text bigger.
  • Describe each image in a short sentence. Those descriptions help people who use screen readers.

If something goes wrong

A frame mentions a tool I do not need
Change what you sell in the left panel. A printable download has no box frames and a boxed game has no print-and-assemble frame.
I have no rulebook
Untick the rulebook option. Frame 11 becomes the card back.
My list disappeared
It is saved in this browser. Clearing your browser data removes it, so download the list now and then.
The copy button does nothing
Select the text by hand and copy it.

What the Studio writes on the five Listing Images

The Studio does not take free text for these images. It writes them from the fields you fill in in Station 1: Deck title, Brand or shop name, Number of cards, Players, Play time, Ages, Game type and Paper. Type the same values here to preview exactly what each image will say, and fix anything before you download.

Phone legibility check

On a phone the whole image shrinks to a small thumbnail. This works out how big the text must be in your original image so it is still readable there.

FormatExport width (px)Text at least (px tall)As a share of the width

Export widths are common sizes, not requirements: check what the place where you publish asks for. Text at least = smallest readable text × export width ÷ thumbnail width.

Style sheet: one look for the whole set

Decide the look once, then use it on every image. The Listing Images tab has many ready palettes and a Custom one, plus a choice of frame, background texture and title font. The Mockup Builder has its own looks, backgrounds, shadow, vignette and caption. The contrast check tells you if your text colour is readable on your background.

    The four image formats

    The Mockup Builder in the Studio has seven formats; the four in this shot list are Square, Landscape, Portrait and Pin (it also has Story, Wide and Shop banner). Pick the one that matches where you will show the image, and use the same one across a set where you can.
